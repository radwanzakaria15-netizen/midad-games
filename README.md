# ركن ألعاب مِداد

مستودع مستقل لألعاب منصة مِداد، بتصميم متوافق مع الهواتف والحواسيب.

## الألعاب
- سباق الحروف
- أكمل الجملة
- صح أم خطأ

## الألعاب الأصلية
ملفات الألعاب الأصلية التسعة التي أرسلها صاحب المشروع ستضاف إلى مجلد `games/original/` بعد رفع ملفاتها الكبيرة. لم تُستبدل أو تُعدّل نسخها.

## التشغيل
افتح `index.html` محلياً، أو فعّل GitHub Pages من إعدادات المستودع واختر الفرع `main` والمجلد `/(root)`.
